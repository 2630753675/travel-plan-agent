ENTRY · FOUR DIRECTIONS

四个开场，选一个继续。

全部纯 CSS/SVG、无脚本；每个页面单独打开、刷新即重播。主按钮都指向已上线的服务，次级按钮打开一条真实运行。

01 / BINDING · V2

装订

五条线合成面板；印章带信号条，悬停联动当日线，点面板可装订；背景是轨道、装订线与地网组成的场景（CSS 可见，Canvas 粒子为增强）。

打开 01-binding.html →
02 / CLOCK

时刻

一条时间轴扫过 08–22，五天依次亮起。最有旅行感，但一直在动。

打开 02-clock.html →
03 / ACCORDION

折叠

一张面板逐层展开，每一层是一天。物理感最强，也最挑实现精度。

打开 03-accordion.html →
04 / ARC

航线

等高线与一条弧线，光点沿路走；鼠标移动时背景分层。最“旅行”，也最安全。

打开 04-arc.html →
我的推荐：01 装订。它只用一个动作讲完“五个角色 → 一份方案”，结束即静止，不抢按钮； 空槽位也不会假装已经排好行程。
如果你想要更强的视觉冲击，可以选 03 折叠；想要更“旅行”，选 04；02 适合做屏保，不适合做入口。
