01

核心任务是一条环，不是一条线

每一环由不同的表达形式承担；改完一处，又回到“看方案”。

01

说需求

一句话即可；结构化字段兜底，没说的部分由团队追问。

自然语言表单标签
02

确认取舍

只有你能定的问题，用选项问；每个选项下面写清代价。

选项卡实时骨架评审预判
03

看方案

先读结论，再按需看时间轴、地图、预算与变更；同一事实的四种投影。

叙事时间轴地图预算diff
04

改一处

在具体某一天上下指令；团队只重排那一天，再评审、再回来。

指令条局部返工版本
