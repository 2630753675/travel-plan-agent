# UI v1 · 设计冻结说明

**定版日期**：2026-11-19
**唯一实现文件**：[09-complete.html](09-complete.html)
**状态**：冻结。后续修改走变更记录，不再整版重画。

## 1. 范围

一条完整链路，六个场景：

| 场景 | 页面 | 解决的问题 |
|---|---|---|
| 01 | 入口 | 这是什么产品、值不值得试 |
| 02 | 需求 | 我要填什么、填完会发生什么 |
| 03 | 取舍 | 选完代价是什么（实时骨架 + 评审预判） |
| 04 | 运行 | 团队到底做了什么（装配线 + 问题清单） |
| 05 | 工作区 | 方案长什么样、怎么改一处 |
| 06 | 交付 | 怎么带走、改了什么 |

## 2. 视觉语言

- **底色**：夜航蓝黑 `#06070C`；表面 `#0B0E15` / `#10141D`
- **文字**：主 `#EEF1F7`，次 `#9AA4B4`，弱 `#626C7C`
- **强调**：靛蓝 `#8B9CFF`，只用于选中、链接、版本
- **语义**：薄荷 `#6FE3C0`（通过/关闭）、琥珀 `#F0B872`（风险/超支）、玫瑰 `#F28BA0`（删除/超支）
- **主按钮**：白底黑字；次按钮：透明 + 1px 描边
- **字体**：Inter / 系统无衬线；数据与时间用等宽；**不使用衬线、不使用金色、不使用纸色**
- **形状**：6–12px 圆角，1px 半透明描边，不用大阴影堆叠

## 3. 类型与间距

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面主标题 | 34–54 | 600，字距 -0.04em |
| 区块标题 | 20–26 | 600 |
| 正文 | 13–15 | 400，行高 1.75 |
| 辅助 / 等宽标签 | 9.5–11 | 400，字距 0.08–0.16em |

间距以 4px 为基数；页面左右留白 28–40px；区块间距 56–72px。

## 4. 动效

| 场景 | 时长 | 规则 |
|---|---|---|
| 场景切换 | 400ms | 8px 上浮 + 淡入 |
| 悬停 | 150–200ms | 只做位移与描边，不弹跳 |
| 装配演示 | 4.5s | 光点沿线走一遍，工位依次打勾，末尾出现「装配完成」 |
| 骨架数值 | 280ms | 切换时轻微上浮，不闪烁 |

全部支持 `prefers-reduced-motion: reduce`。

## 5. 无障碍

- 正文对比度 ≥ 5.9:1；小字不小于 9.5px（等宽标签）
- 隐藏控件使用 clip 方案，仍可聚焦；所有可点元素有 `:focus-visible` 描边
- 选中态不只靠颜色：单选有圆点，选中块有 1px 白描边

## 6. 已知取舍（不是缺陷，是有意为之）

1. 入口用示例日程卡而非真实用户数据；产品化时应由“最近一次规划”生成。
2. 取舍页骨架是前端预演，不是后端算出来的；真正数值以运行结果为准。
3. 装配线的时长为固定演示值，接入真实 SSE 后应改为真实进度。
4. 交付页暂不生成分享链接与 PDF，标注为下一版接入。
5. 工作区时刻表按 08:00–22:00 固定轴；跨夜航班需另做。

## 9. 前端实现状态（2026-11-19）

v1 已落到真实前端，保持接口与状态机不变，只替换渲染层：

- `frontend/src/App.tsx`：六屏（入口 / 需求 / 取舍 / 运行 / 方案 / 交付），保留 SSE、中断恢复、单日返工、版本回滚、分享、访问口令、设置。
- `frontend/src/v1.css`：v1 设计变量与全部组件样式（作用域 `.v1`，不影响旧 Settings 样式）。
- `frontend/src/main.tsx`：追加引入 `v1.css`。
- `frontend/src/App.legacy.tsx`：旧界面备份，验收通过后删除。

验收方式：`npm run build` 通过；用接口夹具（`?plan=demo`）验证方案页、预算页、变更页、块选择、交付页、手机端。

未验证：真实后端的一次完整运行（入口 → 真实 SSE → 方案 → 返工 → 交付）。

## 10. 实现修正（2026-11-19）

真实运行两次后修正：

- 取舍页晚数改为按日期计算，不再硬编码“四晚”；
- 运行页阶段进度改用真实 stage 字段，不再按事件条数推断；
- 方案页同时显示「计划 vN」与「审核 vN」，避免两套版本编号被误读；
- 交付页日期行取当天第一个景点，而不是第一个条目（航班）。
